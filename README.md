# A Domestic Matter: dashboard

Wstępne wyniki artykułu o polskiej debacie o aborcji, projekt Abortion Figurations. Otwórz `index.html` w przeglądarce. Zakładki: Wyniki i Raport.

Wyniki są robocze. Funkcję odniesień i „kim jest my” oznaczył wyłącznie model, bez walidacji przez człowieka, a wersja trójkrajowa nie ma jeszcze wyników. Nie należy ich cytować.

`index.html` to samodzielna kopia dashboardu: dane są wbudowane w plik, a d3 ładuje się z CDN. Plik zawiera tylko dane zbiorcze, bez tekstów źródłowych.
